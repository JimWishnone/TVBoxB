# TVBoxB 软件介绍与使用说明

## 一、软件简介

**TVBoxB**（版本 v0.1.0）是一款基于 macOS 原生界面（AppKit）开发的视频播放软件，可在 **macOS 15 及以上**系统上运行。它同时支持**视频点播**和**视频直播**两大功能，点播与直播数据均来自 TVbox 官方配置源（如 `official.json` / `tvbox.json`）。

软件界面简洁，采用 macOS 默认界面风格并辅以彩色渐变色与毛玻璃材质元素，所有按钮和菜单项均带有图标，方便识别与操作。

## 二、主界面概览

启动软件后会显示主窗体：首次启动时按当前显示器宽窄自动适配窗口尺寸，之后每次启动自动恢复上次关闭时的窗口大小与位置。窗体左侧为**彩色渐变背景的功能导航栏**，包含 8 个可选项目：

| 导航项 | 功能说明 |
|---|---|
| TVBox数据源列表 | 查看、刷新并检测所有数据源的可用性 |
| 搜索 | 在所有数据源中跨站点搜索影片 |
| 点播 | 按数据源浏览分类、搜索并播放视频 |
| 直播 | 浏览、搜索并播放直播频道 |
| 收藏夹 | 收藏点播与直播视频，支持排序与续播 |
| 历史 | 查看最近 30 条播放记录并可续播 |
| 设置 | 配置点播 / 直播数据源地址 |
| 关于 | 查看软件信息、联系方式与资助信息 |

点击左侧任意一项，右侧内容区即切换到对应功能页面。

## 三、各功能模块使用说明

### 1. TVBox数据源列表

- 启动后自动列出本次可用的所有 TVBox 数据源，表格包含**名称、类型、地址、可用状态**四列；
- 点击右上角**「刷新」**按钮可重新加载并检测数据源列表；
- 检测过程中会弹出**「检查中」**提示，检测完成后显示**「可用」或「不可用」**；
- **不可用的数据源会被自动排到最后**，其他模块使用数据源时会跳过它们；
- **双击某行数据源名称**，可将其地址复制到剪贴板，方便分享或备份。

### 2. 搜索

- 在顶部搜索框输入片名，按回车或点击**「搜索」**按钮，即可在**所有可用数据源**中跨站点搜索；
- 输入过程中会**实时**显示搜索结果；
- 每个结果卡片分两行显示：**数据源名称**和**共 X 集**，并尽量加载海报图，无法加载时自动显示默认占位图；
- 搜索结果会按**关键词相似度从高到低**排序；
- 搜索框下方会保留**搜索关键词历史**：点击某个关键词可快速回填并重新搜索，点击关键词旁的 **×** 可删除该条历史记录。

### 3. 点播

- 顶部可通过**「站点」下拉框**切换数据源；切换后会自动清空旧列表，并加载新站点的分类与内容；
- 站点下方是**分类栏**，点击分类可筛选该分类下的视频，列表**支持分页**，滚动到底部会自动加载下一页；
- 也可在右侧搜索框**在当前站点内搜索**影片；
- **点击视频列表中的任意项目**，会弹出**详情模态窗口**，展示：
    - 左侧视频海报，海报下方为**「收藏」按钮**；
    - 右侧视频名称、类型、年代、导演、主演、简介，以及**线路**和**集数**选择；
    - 底部**「播放」按钮**；
- 点击海报下方的**「收藏」按钮**可收藏该视频，再次点击取消收藏（未收藏时显示空心星标与「收藏」，已收藏时显示填充星标与「已收藏」）；
- 点击**「播放」按钮**后，模态窗口自动关闭，并跳转到播放器播放该视频。

### 4. 直播

- 顶部工具栏提供：**直播源选择、分组选择、刷新、频道名称查找**；
- 频道列表最前面显示**频道图标**（无法加载时自动显示频道首字母图标）；
- 频道名称左侧显示**收藏按钮**（悬停时出现空心星标，已收藏的频道常驻填充星标），点击即可收藏或取消收藏；
- **相同的频道会合并显示**，不同「数据源 + 线路」显示为不同线路，并完整显示线路名称；
- 列表包含**频道、分组、数据源来源、线路**等列，点击列头可**按该列排序**；
- **双击频道**开始播放；
- 播放直播时：
    - **上 / 下方向键**（或点击上下图标）切换上一个 / 下一个频道；
    - **左 / 右方向键**（或点击左右图标）切换当前频道的不同线路；
    - 切换时播放窗体的标题文字会同步更新；
    - 当前线路播放失败时会**自动切换到下一线路**。

### 5. 收藏夹

收藏夹用于收藏用户感兴趣的点播视频和直播频道，收藏内容保存在本地，重启软件后依然保留。

- 收藏夹列表包含**名称、类型、详情**三列，按收藏顺序显示；
- **拖动任意一行**可调整收藏条目的顺序；
- **双击某个条目**可直接播放：点播视频会自动重新加载并播放，直播频道会直接开始播放；
- **鼠标移动到条目上**会显示删除按钮，点击即可删除该条收藏记录；
- 收藏来源：
    - **点播**：在视频详情模态窗口中点击**「收藏」按钮**收藏，再次点击取消；
    - **直播**：在直播频道列表中悬停到频道行，点击频道名称左侧的**收藏按钮**收藏，再次点击取消；
- 收藏状态通过**空心星标（未收藏）** 与 **填充星标（已收藏）** 区分。

### 6. 历史

- 显示最近播放过的**点播和直播**视频记录；
- 按**从新到旧**排序，最多保存**最近 30 条**；
- 每条记录完整保存视频的全部数据（站点、线路、集数、播放进度等）；
- **点击记录**即可按原记录信息重新加载并**继续播放**；
- 点击右上角**「清空」按钮**可一键清空全部历史记录。

### 7. 设置

视频数据源分为两部分，各对应一个地址输入框：

- **点播数据源（主数据源，必填）**：用于点播搜索和分类浏览，仅支持填写一个 URL；
- **直播视频源（专属直播的数据源，选填）**：用于直播频道列表。

操作方式：

- 在两个输入框中分别填写点播、直播数据源地址（输入框文字已放大显示，方便阅读与输入）；
- 点播数据源在保存前会进行**可访问、可解析、TVBox 格式验证**，验证通过后才可保存；
- 若点播数据源地址中包含直播数据源，保存时会**弹出列表供你选择其中一个**保存到直播数据源（也可选择「不选择」忽略）；
- 若点播数据源地址中不包含直播数据，则仅保存你手动填写的专属直播数据源；
- 修改完成后点击**「保存并重新加载」**，新配置立即生效，并作用于全局所有模块。

关于页采用**蓝→紫→粉彩色渐变背景**，内容包含：

- 软件名称 **TVBoxB**、版本号 **v0.1.0**、简要介绍，以及版权信息**「版权所有 © 2026 iGruel.com」**；
- 技术支持邮箱 **ibmos_2@163.com**：
    - 点击**「复制」**将邮箱复制到剪贴板；
    - 点击**「发送邮件」**直接唤起系统邮件客户端；
- **「资助本软件」**信息：说明本软件免费开放使用、欢迎自愿赞助，并展示**微信支付二维码**，二维码下方提示**「请使用微信扫码资助本软件」**。

## 四、播放器说明

无论是点播还是直播，所有视频都在**同一个播放器窗体**中播放（全局仅一个播放窗口）。

- 视频播放组件**占满整个窗口**，点击视频可**播放 / 暂停**；
- 顶部以**渐变蒙版标题覆盖层**显示当前视频信息，保证在任意画面上清晰可读；
- 底部为**毛玻璃材质控制条**（圆角 HUD 风格），包含：播放 / 暂停、上 / 下频道、线路选择、上 / 下线路、集数选择、**隐藏 / 恢复显示**、全屏等按钮；
- 支持两种扩展播放模式，并可随时返回：
    - **全窗口播放（隐藏模式）**：点击控制条上的**「隐藏 / 恢复显示」按钮**（眼睛图标），窗口大小位置不变，视频组件最大化充满整个窗口，并隐藏标题与控制条；此时画面右上角会显示**「恢复显示」按钮和 X 按钮**，点击按钮或按 **X 键**即可恢复显示；
    - **全屏播放**：点击全屏按钮进入系统全屏，隐藏其他组件，随时可退出全屏返回；
- 播放直播时，可使用**上 / 下方向键**切换频道、**左 / 右方向键**切换线路。

## 五、菜单栏快捷键

菜单栏各项均带图标，常用操作包括：

- **TVBoxB**：关于 TVBoxB、退出（⌘Q）；
- **文件**：关闭窗口（⌘W）、重新加载配置（⌘R）；
- **编辑**：撤销（⌘Z）、重做（⇧⌘Z）、剪切（⌘X）、拷贝（⌘C）、粘贴（⌘V）、全选（⌘A）。
