TVBoxB 软件介绍与使用说明
一、软件简介
TVBoxB（版本 v0.0.1）是一款基于 macOS 原生界面（AppKit）开发的视频播放软件，可在 macOS 15 及以上系统上运行。它同时支持视频点播和视频直播两大功能，点播与直播数据均来自 TVbox 官方配置源（如 official.json / tvbox.json）。

软件界面简洁，采用 macOS 默认界面风格，所有按钮和菜单项均带有图标，方便识别与操作。

二、主界面概览
启动软件后会显示主窗体（默认 1080×700），窗体左侧为功能导航栏，包含 7 个可选项目：

导航项	功能说明
TVBox数据源列表	查看、刷新并检测所有数据源的可用性
搜索	在所有数据源中跨站点搜索影片
点播	按数据源浏览分类、搜索并播放视频
直播	浏览、搜索并播放直播频道
历史	查看最近 30 条播放记录并可续播
设置	配置点播 / 直播数据源地址
关于	查看软件信息、联系方式与赞助信息
点击左侧任意一项，右侧内容区即切换到对应功能页面。

三、各功能模块使用说明
1. TVBox数据源列表
启动后自动列出本次可用的所有 TVBox 数据源，表格包含名称、类型、地址、可用状态四列；
点击右上角**「刷新」**按钮可重新加载并检测数据源列表；
检测过程中会弹出**「检查中」提示，检测完成后显示「可用」或「不可用」**；
不可用的数据源会被自动排到最后，其他模块使用数据源时会跳过它们；
双击某行数据源名称，可将其地址复制到剪贴板，方便分享或备份。
2. 搜索
在顶部搜索框输入片名，按回车或点击**「搜索」按钮，即可在所有可用数据源**中跨站点搜索；
输入过程中会实时显示搜索结果；
每个结果卡片分两行显示：数据源名称和共 X 集，并尽量加载海报图，无法加载时自动显示默认占位图；
搜索结果会按关键词相似度从高到低排序；
搜索框下方会保留搜索关键词历史：点击某个关键词可快速回填并重新搜索，点击关键词旁的 × 可删除该条历史记录。
3. 点播
顶部可通过**「站点」下拉框**切换数据源；切换后会自动清空旧列表，并加载新站点的分类与内容；
站点下方是分类栏，点击分类可筛选该分类下的视频，列表支持分页，滚动到底部会自动加载下一页；
也可在右侧搜索框在当前站点内搜索影片；
点击视频列表中的任意项目，会弹出详情模态窗口，展示：
左侧视频海报；
右侧视频名称、类型、年代、导演、主演、简介，以及线路和集数选择；
底部**「播放」按钮**；
点击**「播放」按钮**后，模态窗口自动关闭，并跳转到播放器播放该视频。
4. 直播
顶部工具栏提供：直播源选择、分组选择、刷新、频道名称查找；
频道列表最前面显示频道图标（无法加载时自动显示频道首字母图标）；
相同的频道会合并显示，不同「数据源 + 线路」显示为不同线路，并完整显示线路名称；
列表包含频道、分组、数据源来源、线路等列，点击列头可按该列排序；
双击频道开始播放；
播放直播时：
上 / 下方向键（或点击上下图标）切换上一个 / 下一个频道；
左 / 右方向键（或点击左右图标）切换当前频道的不同线路；
切换时播放窗体的标题文字会同步更新；
当前线路播放失败时会自动切换到下一线路。
5. 历史
显示最近播放过的点播和直播视频记录；
按从新到旧排序，最多保存最近 30 条；
每条记录完整保存视频的全部数据（站点、线路、集数、播放进度等）；
点击记录即可按原记录信息重新加载并继续播放。
6. 设置
视频数据源分为两部分：

点播数据源（主数据源，必填）：用于点播搜索和分类浏览；
直播视频源（专属直播的数据源，选填）：用于直播频道列表。
操作方式：

直接在表格的地址单元格点击即可编辑；
使用**「添加」「删除」「恢复默认」**（点播）/ 「添加」「删除」「清空」（直播）按钮管理数据源；
修改完成后点击底部**「保存并重新加载」**，新配置立即生效，并作用于全局所有模块。
7. 关于
显示软件名称 TVBoxB、版本号 v0.0.1、版权信息与简要介绍；
显示技术支持邮箱 ibmos_2@163.com：
点击**「复制」**将邮箱复制到剪贴板；
点击**「发送邮件」**直接唤起系统邮件客户端；
显示**「赞助软件」**信息。
四、播放器说明
无论是点播还是直播，所有视频都在同一个播放器窗体中播放（全局仅一个播放窗口）。

视频播放组件占满整个窗口，点击视频可播放 / 暂停；
当前视频信息覆盖叠加显示在画面上；
支持两种扩展播放模式，并可随时返回：
全窗口播放：窗口大小位置不变，视频组件最大化充满整个窗口，并隐藏其他组件；此时会显示**「返回正常窗体」按钮和 X 按钮**，点击按钮或按 X 键即可返回正常窗体；
全屏播放：进入系统全屏，隐藏其他组件，随时可退出全屏返回。
五、菜单栏快捷键
菜单栏各项均带图标，常用操作包括：

TVBoxB：关于 TVBoxB、退出（⌘Q）；
文件：重新加载配置（⌘R）；
编辑：撤销（⌘Z）、重做（⇧⌘Z）、剪切（⌘X）、拷贝（⌘C）、粘贴（⌘V）、全选（⌘A）。
